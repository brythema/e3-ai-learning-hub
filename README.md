# E³ Hub · Artificial Intelligence — Interactive Learner's Manual

A self-contained, single-file interactive HTML reader for the E³ Hub Artificial Intelligence course.

- **Course creator:** Bright Ameh — Encourage Excellence Early (E³)
- **Website:** [www.eee3.com.ng](https://www.eee3.com.ng)
- **Live reader:** opens directly in any browser — no installation, works offline after saving the file.

## Contents

The reader includes the full course text across searchable reading pages:

- Before you begin: preparing your AI practice environment
- Module 1: Introduction to Artificial Intelligence
- Lessons 1–6 (what AI is, its history, types and categories, how it thinks and answers, context and verification, where it runs, how it is trained)
- Final chapter: six guided practical projects

## Features

- Search across the whole course
- Personal notes stored on your device
- Section progress tracking
- Light / dark themes and adjustable text size

## Use it

Just open `index.html` in a browser, or visit the live deployment linked above.
